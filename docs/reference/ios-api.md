# Hypo for iOS API

The [combined DocC reference](https://hypo.graycard.app/docs/ios-api/) documents the first-party Swift packages used by Hypo for iPhone. It includes tutorials for an end-to-end film-roll workflow, deterministic meter feature work with `SimulatedMeterDevice`, and meter calibration.

DocC describes client APIs and package boundaries. The [Lexicon reference](./lexicons/index.md) remains canonical for the fields and constraints of public `app.graycard.*` records.

These pages cover Hypo, the metadata, metering, field-logging, and development-timing app. Gray Card is a separate photo editor with its own documentation.
