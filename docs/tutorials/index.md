# Tutorials

Tutorials follow one task from its starting state to a working result:

- [Getting started with Hypo](./getting-started.md) creates film reserve, a physical roll, a shoot, and an exposure.
- [Publish to Discover](./publish-to-discover.md) makes a setup findable through its opt-in registry backlink.
- [Import + EXIF](./import-and-exif.md) uploads a gallery while keeping model observations distinct from owned gear.

Repository setup, generated records, and the fixture PDS are covered separately under [Developer tutorials](./developer.md).

If you already know the outcome you need, turn to the [how-to guides](../how-to/index.md). The [lexicon reference](../reference/lexicons/index.md) documents every NSID, field, ref, constraint, and known-value set.
