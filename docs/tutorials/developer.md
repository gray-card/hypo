# Developer tutorials

These tutorials cover the repository and generated schema runtime:

- [Schema development setup](./schema-development-setup.md) installs the workspace, regenerates lexicon artifacts, and runs the focused checks.
- [Build a first record](./first-record.md) connects namespace constants to the runtime validator.
- [Run against the fixture PDS](./run-against-fixture-pds.md) starts the deterministic development environment and exercises a write.

For the application itself, begin with [Getting started with Hypo](./getting-started.md).
