# `SystemIntegrationKit`

Expose Hypo actions and state to deep links, App Intents, controls, and widgets.

## Overview

SystemIntegrationKit parses app routes and defines the small, sendable snapshot shared with system surfaces. The app composition root supplies the live action handlers; extensions do not open feature persistence directly.
